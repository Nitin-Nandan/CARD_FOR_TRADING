# Project CARD: Nifty 500 Predictive Engine
## Channel Aligned Robust Blend Transformer for Intraday Trading

Project CARD is a high-frequency predictive framework based on the ICLR 2024 paper "CARD: Channel Aligned Robust Blend Transformer for Time Series Forecasting". It is engineered to predict 15-minute forward returns across the Nifty 500 universe using an 81-channel feature suite.

## 🏗️ System Architecture
The project follows a strict **Library-Factory-Trigger** modular design to ensure scalability and research integrity:

- **`src/` (The Library):** Core mathematical truth including the CARD Transformer, RevIN layers, and the 81-channel Feature Engine.
- **`pipeline/` (The Factory):** Automated data lifecycle management (Auth → Download → Process → Window).
- **`scripts/` (The Tools):** Diagnostic and execution triggers for training and validation.
- **`vendor/` (External):** Houses the custom fork of `pandas_ta` for specialized indicator math.

## 🚀 Quick Start Pipeline


## 🔬 Technical Specifications
- **Feature Suite (81 Channels):** Includes Momentum (RSI/MACD), Volatility (Parkinson/GK), Volume (VWAP/MFI), and Phase 3 Market Regimes.
- **Model Core:** Transformer-based architecture with Dual-Attention (Token & Channel) and EMA-smoothed Query/Key matrices.
- **Loss Function:** `CombinedReturnLoss` using Magnitude-Scaled MAE and a high-penalty Directional Weight to maximize signal-to-noise ratio.
- **Data Efficiency:** Utilizes **Index-Based Windowing** via `.npz` metadata and `.npy` memory-mapping to handle TB-scale datasets with ~0 MB RAM overhead.
